# D' La Abuela y el Lobo — Prototipos web

3 propuestas de diseño para la página web de **D' La Abuela y el Lobo** (marca gastronómica artesanal de Ecuador).

## 🌐 Demo en vivo

👉 **[Ver los 3 prototipos](https://tarius-sas.github.io/abuela-lobo-prototipos/)**

## Las 3 direcciones

| | Concepto | Vibe |
|---|---|---|
| **A · Tradición Cálida** | Cuaderno de recetas vintage + animaciones modernas | Nostálgico, "hecho con tiempo" |
| **B · Editorial Premium** | Revista gastronómica curada | Sofisticado, magazine-style |
| **C · Folklore Moderno** | Personajes Abuela vs Lobo, bento bold | Vibrante, redes-friendly |

## Stack del prototipo

- HTML + Tailwind CSS (CDN)
- GSAP 3.12.5 + ScrollTrigger (animaciones)
- Lenis (smooth scroll)
- Fotos reales extraídas del catálogo 2025

## Próximo paso

El cliente escoge una dirección. Implementación final en **Next.js 15 + shadcn/ui + Tailwind v4 + Vercel**.
